# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
- **Teachers**: Create and manage quizzes, build questions, and view statistics.
- **Students**: Take timed quizzes and view personal progress.
- **Administrators**: Manage users and global settings.

## Product Purpose
To facilitate online multiple-choice assessments for educational environments, enabling teachers to evaluate students efficiently.

## Positioning
A simple, easy-to-use quiz tool for everyday classroom testing, enhanced by features like real-time countdowns and timed answer releases.

## Operating Context
Classroom and remote learning environments where teachers administer everyday tests and students complete them within specified time limits.

## Capabilities and Constraints
- **Capabilities**: Real-time countdown timers, auto-submission, timed answer release, question palettes, and multiple question types.
- **Constraints**: Must maintain the existing React + TypeScript + Vite + Tailwind CSS architecture.

## Brand Commitments
The interface follows a modern Pastel color scheme with support for Dark Mode.

## Product Principles
1. **Simplicity First**: Workflows should be intuitive enough for everyday classroom use without extensive training.
2. **Reliable Assessment**: Time constraints and auto-submissions must be strictly enforced.
3. **Accessible Clarity**: The interface must remain clear and easy on the eyes (dịu mắt) for prolonged reading.
